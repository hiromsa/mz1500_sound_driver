# MZ-1500 キーボードマトリクス (8255) 仕様
キーワード: `MZ-1500`, `Keyboard`, `KeyMap`, `8255`, `PPI`, `E000h`, `Input`, `Emulator`, `仕様`
【情報源: CommonSourceProjectSrc/source/src/vm/mz700/keyboard.cpp, memory.cpp】

MZ-1500のキーボードスキャンは、8255 (PPI) の I/O ポート `E000h` と `E001h` を介して行われます。

## 1. I/O ポートとデコード回路 (LS145)
*   **`E000h` (W)**: ポートA。列(Column)選択用のストローブ出力。
    *   `Bit 7`: 556RST (カーソル点滅タイマリセット)
    *   `Bit 3 - 0 (PA0〜PA3)`: キーボード走査のための行指定ストローブ (`0` 〜 `9`)
*   **`E001h` (R)**: ポートB。指定されたストローブに対する行(Row)入力。
    *   `Bit 7 - 0 (PB0〜PB7)`: スキャンされた各キーの状態。押下されているビットが `0`（負論理）になります。

テクニカルノート P184 によれば、キーボードスキャン回路は 8255 のポート A の下位4ビット (PA0〜PA3) を **LS145 デコーダ** に入力し、そこで10本のストローブ信号に変換してキーマトリクスへ出力しています。そしてマトリクスの各交点にあるスイッチ（キー）の状態が、ポート B (PB0〜PB7) から読み取られる仕組みです。
