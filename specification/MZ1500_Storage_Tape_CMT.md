# MZ-1500 データレコーダ (CMT) & テープイメージ (.MZT) 仕様
キーワード: `MZ-1500`, `CMT`, `Tape`, `MZT`, `PWM`, `Storage`, `Media`, `E002h`, `Emulator`, `仕様`
【情報源: CommonSourceProjectSrc/source/src/vm/mz700/datarec.cpp, memory.cpp】

MZ-1500 はカセットデータレコーダとの通信を 8255 (PPI) のポート C を介して行います。エミュレータでは `.MZT` ファイルが PWM 波形に変換されて読み込まれます。

## 1. ポート E002h (8255 Port C) のアサイン
*   `Bit 1` (PC1): WRITE DATA (出力)
*   `Bit 3` (PC3): MOTOR ON/OFF (出力, 1でモーターON)
*   `Bit 4` (PC4): MOTOR REMOTE (入力)
*   `Bit 5` (PC5): READ DATA (入力)

## 2. 信号フォーマット (PWM変調)
データはPWM（パルス幅変調）によって表現されます。エミュレータ (`datarec.cpp`) におけるサンプリングレート 48kHz 換算でのパルス幅は以下の通りです。
*   **データ `1` (長パルス)**: High 約 500μs, Low 約 600μs (合計 約 1.1ms)
*   **データ `0` (短パルス)**: High 約 230μs, Low 約 310μs (合計 約 0.54ms)

## 3. .MZT ファイルフォーマット
`.MZT` ファイルは、ヘッダ部 (128 バイト) とプログラム本体で構成されます。
*   **ヘッダ部 (128 Bytes)**
    *   `00h`: ファイル属性 (`01h`=機械語, `02h`=BASIC, `03h`=データ, `04h`=拡張データ)
    *   `01h - 11h`: ファイルネーム (ASCII最大17文字, 0Dh終端)
    *   `12h - 13h`: ファイルサイズ (リトルエンディアン)
    *   `14h - 15h`: ロードアドレス (メモリの読み込み開始番地)
    *   `16h - 17h`: 実行開始アドレス (読み込み後のJP先)
    *   `18h - 7Fh`: コメント等 (予約領域)
*   エミュレータ上では、この 128 バイトと本体データの末尾にチェックサム (出力したビット1の数の下位16ビット) を付加して波形を生成します。
