# MZ-1500 モニタ BIOS システムコール仕様
キーワード: `MZ-1500`, `BIOS`, `Monitor ROM`, `RST 18H`, `RST 3`, `System Call`, `Software`, `Emulator`, `仕様`
【情報源: MZ1500_BIOS_Monitor_Spec】

MZ-1500 のシステムROM (モニタROM) には、文字表示やテープ/QD制御などを行うためのサブルーチンが用意されています。

## 1. システムコール (RST 18H)
`RST 18H` (命令コード `DFh`) の次のバイトに機能コード (シーケンスナンバー) を記述して呼び出す主要機能です。

*   `01h`: **CR1** - CRTへ改行を出力する。
*   `02h`: **CR2** - カーソルが行の先頭でなければ改行を出力する。
*   `03h`: **CRT1C** - CRTへ1文字出力する。制御コードは実行される。 (入力: `A` = アスキーコード)
*   `0Bh`: **&MSG** - CRTかプリンタに文字列を表示する。(入力: `DE` = 文字列のポインタ、文字列の終端は `00H`)
*   `1Eh`: **PNT1** - VRAM上のアドレスを計算する。(入力: `L` = X座標, `H` = Y座標、または `POINTX, POINTY` ワークエリアを使用)
*   `21h`: **PLAY** - 音楽演奏。(入力: `DE` = ミュージックデータポインタ、エンドコードは `00H` または `0DH`)
*   `22h`: **SOUND** - PSGを直接コントロールする。(入力: `A` >= 80H でレジスタセット、`A` < 80H で音階(`A`)と音長(`DE` 10ms単位)をセット)
*   `23h`: **MCTRL** - MUSICに関する動作。(入力: `B`=0 初期化, `B`=1 PLAY開始, `B`=2 MUSIC停止, `B`=3 MUSIC待ち)
*   `30h`: **LOADF** - ファイルをロードする。事前に `DEVFN`, `LOPEN` などの呼び出しが必要。
*   `31h`: **SAVEF** - ファイルをセーブする。
*   `39h`: **DIR** - ディレクトリを表示する。

## 2. 主要サブルーチン (ダイレクト CALL エントリ)
以下のルーチンは直接 `CALL` 命令で呼び出すことができます。

*   `$0003` (**GETL**): キーボードから1行入力。(入力: `DE` = バッファアドレス、出力: `CF` = BREAK時1)
*   `$0012` (**CRTIC**): CRTへ1文字出力。(入力: `A` = アスキーコード)
*   `$001B` (**INKEY$**): キーボードから1文字入力。押されるまで待つ。(出力: `A` = 文字コード)
*   `$0030` (**MUSIC**): 音楽を演奏する。
*   `$0047` (**MLDSP**): ミュージックを停止する。
*   `$00E8` (**LDAHL**): VRAM/IO/拡張バンクからデータを読み出す。(入力: `HL` = アドレス、出力: `A` = データ)
*   `$00EE` (**LDHLA**): VRAM/IO/拡張バンクへデータを書き込む。(入力: `HL` = アドレス、`A` = データ)
*   `$0108` (**PUSHR**): サブルーチン内で `HL, DE, BC, IX` レジスタをセーブ(PUSH)する。
*   `$011B` (**CHKACC**): Aレジスタをいくつかのデータと比較する。
