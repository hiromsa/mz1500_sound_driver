# MZ-1500 拡張サウンド YM2151 (OPM) 仕様
キーワード: `MZ-1500`, `Sound`, `YM2151`, `OPM`, `FM音源`, `Emulator`, `仕様`
【情報源: MZ-1500_YM2151_Spec, CommonSourceProjectSrc/source/src/vm/ym2151.cpp】

MZ-1500 では拡張オプションとして YM2151 (OPM) ボードを搭載することができ、8音ポリフォニックのFM音源による高度なサウンド再生が可能です。

## 1. I/O ポート
*   **`E008h` (W)**: YM2151 (OPM) レジスタのアドレス指定 (Address Port)
*   **`E009h` (R/W)**: YM2151 (OPM) データレジスタへの書き込み / ステータス読み込み (Data Port)
*   *注意*: `E008h` はジョイスティックなどの入力用にも使われているマルチプレクサ機能を持つポートですが、OPM拡張時にはアドレスレジスタとしても機能します。

## 2. 割り込みルーティングとタイマー
YM2151 内部にはタイマー A とタイマー B が搭載されています。
*   YM2151 の IRQ (割り込み) 出力ピンは、システムの INT 割り込みロジックに接続されており、タイマー割り込みを発生させることができます。
*   音楽ドライバ (BGM再生など) において、精度の高いテンポ同期が必要な場合は、PIT ではなくこの YM2151 内蔵タイマーを IM 1 または IM 2 割り込みのトリガーとして利用するソフトウェアが存在します。

## 3. レジスタと使用例
詳細なレジスタマップは一般的な YM2151 (OPM) と同様です。
*   `20h - 3Fh`: L/Rパン、フィードバック、アルゴリズム (CT/FB/ALG)
*   `40h - 5Fh`: DT1, MUL
*   `60h - 7Fh`: TL (トータルレベル)
*   `80h - 9Fh`: KS, AR
*   `A0h - BFh`: AME, D1R
*   `C0h - DFh`: DT2, D2R
*   `E0h - FFh`: D1L, RR
