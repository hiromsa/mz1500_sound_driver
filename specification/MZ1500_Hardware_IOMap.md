# MZ-1500 全I/Oポートマップ
キーワード: `MZ-1500`, `I/O Port`, `Map`, `Emulator`, `仕様`
【情報源: MZ-1500 テクニカルノート 各章, 紅茶羊羹氏サイト I/O Map】

エミュレータの I/O ハンドラ実装の要となる、MZ-1500の全I/Oポートのアドレスマップです。

## メモリマップド I/O (メモリ空間 E000h〜EFFFh)
*   **`E000h` (W)**: 8255 Port A (キーボード・ストローブ出力)
*   **`E001h` (R)**: 8255 Port B (キーボード・マトリクス入力)
*   **`E002h` (R/W)**: 8255 Port C (システム制御用フラグ、CMT、サウンドマスク)
*   **`E003h` (W)**: 8255 コントロールレジスタ
*   **`E004h` (R/W)**: 8253 PIT Ch.0 (BEEP音, PIO A4割り込み用)
*   **`E005h` (R/W)**: 8253 PIT Ch.1
*   **`E006h` (R/W)**: 8253 PIT Ch.2
*   **`E007h` (W)**: 8253 PIT コントロールレジスタ
*   **`E008h` (R)**: ジョイスティック (PWM入力) / V-BLANKステータス
*   **`E008h` (W)**: YM2151 (OPM) アドレスレジスタ (オプション)
*   **`E009h` (R/W)**: YM2151 (OPM) データレジスタ / ステータス (オプション)

## ダイレクト I/O (Z80 IN/OUT 命令)
*   **`D8h〜DBh`**: FDDコントローラ (MB8876) レジスタ
*   **`DCh, DDh`**: FDD モータON/ドライブセレクト, ヘッドセレクト
*   **`E0h〜E4h` (W)**: メモリバンク切り替え (ROM/RAM/VRAMマップ変更)
*   **`E5h` (W)**: PCG RAM へのマッピング有効化 (バンク指定)
*   **`E6h` (W)**: PCG RAM マッピング解除
*   **`E9h` (W)**: PSG 1 & PSG 2 同時出力 (デュアルモノラル)
*   **`F0h` (W)**: PCG/テキスト 優先度(Priority) 設定
*   **`F1h` (W)**: カラーパレット設定
*   **`F2h` (W)**: PSG 1 (L-Ch.) 出力
*   **`F3h` (W)**: PSG 2 (R-Ch.) 出力
*   **`F4h〜F7h` (R/W)**: Z80 SIO (QuickDisk用)
*   **`FCh〜FFh` (R/W)**: Z80 PIO (プリンタポート制御等)
