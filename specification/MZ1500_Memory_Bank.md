# MZ-1500 メモリバンク切り替え仕様
キーワード: `MZ-1500`, `Memory Bank`, `I/O Port`, `E0h`, `E1h`, `E2h`, `E3h`, `E4h`, `E5h`, `E6h`, `Emulator`, `仕様`
【情報源: 紅茶羊羹氏サイトMZ-700/1500 I/O Map, CommonSourceProjectSrc/source/src/vm/mz700/memory.cpp】

MZ-1500では、I/Oポート(0xE0 〜 0xE6)への **OUT命令 (Aレジスタの内容は無視)** によって、アドレス空間の割り当て(バンク)を動的に切り替えます。

## 1. バンク切り替えポート一覧 (OUT)
*   **`E0h`**: VRAM・I/O 空間 (`D000h`〜`FFFFh`) を **メインRAM** に割り当てます。
*   **`E1h`**: `D000h`〜`FFFFh` を **VRAM & I/O 領域** に割り当てます。(通常状態)
*   **`E2h`**: `0000h`〜`0FFFh` を **モニタROM (IPL)** に割り当てます。
*   **`E3h`**: `0000h`〜`0FFFh` を **メインRAM** に割り当てます。(通常状態)
*   **`E4h`**: `0000h`〜`0FFFh` を **辞書ROM / CGROM (読み取り専用)** に割り当てます。
*   **`E5h`**: PCGモードを有効化し、`D000h`〜`EFFFh` に **PCG-RAM (8KB)** をマッピングします。
    *   この時、出力データの **下位2ビット (1〜3)** によって、B (Blue), R (Red), G (Green) の各プレーンのPCG RAMバンクが選択されます。
*   **`E6h`**: PCGモードを解除し、通常のマッピング(`E0h` または `E1h` の状態)に戻します。
