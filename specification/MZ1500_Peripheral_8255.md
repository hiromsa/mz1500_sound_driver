# MZ-1500 システム制御 8255 (PPI) 詳細仕様
キーワード: `MZ-1500`, `8255`, `PPI`, `Port C`, `E002h`, `システムフラグ`, `Emulator`, `仕様`
【情報源: MZ-1500 テクニカルノート P184 (図3-37)】

MZ-1500のシステムの中核となる 8255 PPI は、メモリマップドI/Oの `E000h〜E003h` に配置されています。特にポートC (`E002h`) にはシステムを制御するための重要なフラグが密集しています。

## 1. ポート A, B の役割
*   **Port A (`E000h` / OUT)**:
    *   `PA0〜PA3`: キーボードスキャン用の列(Column)ストローブ信号 (LS145デコーダへ接続)
    *   `PA7`: 556RST (タイマリセット信号)
*   **Port B (`E001h` / IN)**:
    *   `PB0〜PB7`: キーボードマトリクスからの行(Row)状態の読み取り

## 2. ポート C (`E002h`) のビットアサイン (システムフラグ)
ポートCは、ビットごとに各周辺回路の制御線（入力/出力）として接続されています。

*   **Bit 0 (PC0 / OUT)**: `SOUNDMSK`
    *   サウンド出力のマスク。`L` (0) にすると PSG 1, PSG 2, BEEP(8253) のすべての音声出力がミュートされます。
*   **Bit 1 (PC1 / OUT)**: `WRITE DATA`
    *   データレコーダ (CMT) へのPWMデータ出力ピンです。
*   **Bit 2 (PC2 / OUT)**: `INTMSK`
    *   システムの割り込みマスク。
*   **Bit 3 (PC3 / OUT)**: `MOTOR ON`
    *   データレコーダ (CMT) のモーター駆動信号。
*   **Bit 4 (PC4 / IN)**: `MOTOR REMOTE`
    *   データレコーダのモーターステータス（リモート）読み取り。
*   **Bit 5 (PC5 / IN)**: `READ DATA`
    *   データレコーダからのPWMデータ入力ピンです。
*   **Bit 6 (PC6 / OUT)**: `556OUT`
    *   ハードウェアタイマー (556) への出力。
*   **Bit 7 (PC7 / IN)**: `VBLNK`
    *   V-BLANK (垂直ブランキング) 状態の読み取りピン。画面描画中かブランキング中かを判定するために使用されます。
