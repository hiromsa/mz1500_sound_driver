# MZ-1500 システムワークエリア・フラグ仕様
キーワード: `MZ-1500`, `Work Area`, `Memory`, `System Flag`, `Software`, `Emulator`, `仕様`
【情報源: MZ1500_BIOS_Monitor_Spec】

MZ-1500 の RAM 空間上（主に `$1000` 番地以降）には、モニタ ROM やシステムが動作状態を保持するためのワークエリアが確保されています。自作ソフトウェアからこれらのフラグを読み書きすることで、システムの状態を制御できます。

## 1. 主要システム変数 (フラグ) とワークエリア
テクニカルノート P142〜P143 より、以下のワークエリアが定義されています。

*   `$0050` (**CMTMSG**): 0の場合 `PLAY`, `WRITING...` などを表示。
*   `$0054` (**CURX**): カーソルX座標 (0〜39 または 0〜79)
*   `$0055` (**CURY**): カーソルY座標 (0〜24)
*   `$005E` (**CROMSL**): CG-ROM セレクト
*   `$0060` (**CURMAK**): カーソル・マーク (ディスプレイ・コード)
*   `$1000` (**ELMD**): ファイルモード (ディレクトリアクセス用)
*   `$1001` (**ELMD1**): ファイルネーム領域 (17バイト)
*   `$1014` (**ELMD20**): ファイルサイズ (2バイト)
*   `$1016` (**ELMD22**): ロードアドレス (2バイト)
*   `$1018` (**ELMD24**): 実行アドレス (2バイト)
*   `$108C` (**CRTMOD**): ディスプレイモード (`0` = グラフィックモード, `1` = テキストモード)
*   `$108D` (**COL**): デフォルトカラー
*   `$1090` (**DISPX**): 0=MSG, 1=MSGX (CRT/LPT用)
*   `$1091` (**FILOUT**): 0=CRT, 1=LPT
*   `$11A4` (**KEYBUF**): キー・インプット・バッファ (270バイト。キーボードからの入力文字列が格納されます)

## 2. システム・バッファ領域
*   `$10A0` - `$10EF`: **モニタ・スタック・エリア** (モニタROMがサブルーチン呼び出し等で使用するスタック空間)
