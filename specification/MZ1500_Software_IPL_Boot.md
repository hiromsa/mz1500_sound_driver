# MZ-1500 IPLブートシーケンスとハードウェア初期化仕様
キーワード: `MZ-1500`, `IPL`, `Boot`, `ROM`, `Init`, `PIO`, `SIO`, `PSG`, `8255`, `Emulator`, `仕様`
【情報源: MZ-1500 テクニカルノート (P76〜P140 IPLリスト解析)】

MZ-1500の電源投入時（リセット時）に実行される Initial Program Loader (IPL) の完全なアセンブラリストから、システムのハードウェア初期化手順が判明しています。エミュレータの実装において、システムリセット時の各チップの初期状態を正確に再現するための重要な情報です。

## 1. ブート開始アドレスとROM構成
*   電源投入時のZ80は `$0000` 番地から実行を開始します。
*   ハードウェアリセット直後は、`E2h` ポートと同等のメモリマッピング状態（モニタROMが `$0000〜$0FFF` に現れる状態）になります。

## 2. 各周辺デバイスの初期化手順 (Init Sequence)

### A. 8255 PPI (I/O ポート E000〜E003h)
*   コントロールレジスタ (`E003h`) に初期化モードワードを書き込みます。
*   `E002h` の Bit 0 (SOUNDMSK) 等を適切に設定し、内蔵スピーカーへの出力を制御します。

### B. Z80 PIO (I/O ポート FC〜FFh)
*   **ポートA (プリンタ制御等)**:
    *   コントロールレジスタへ `0xCF` (モード3: ビット制御) を設定。
    *   I/Oディレクションを設定し、一部を出力、一部を入力（RDA/STA等）にします。
*   **ポートB (データ等)**:
    *   コントロールレジスタへ `0xCF` (モード3: ビット制御) または出力モードを設定。

### C. Z80 SIO (I/O ポート F4〜F7h / QD制御用)
*   **Ch.B コントロール (`F7h`) / Ch.A コントロール (`F6h`)**:
    *   チャネルリセットコマンド（WR0）を発行し、シリアル通信を停止・初期化します。
    *   QDからの非同期な割り込みや誤動作を防ぐためにレジスタをクリアします。

### D. サウンド (PSG: SN76489AN / I/O ポート F2h, F3h)
*   IPLでは、起動時のノイズを防ぐため、PSGの全出力を即座にミュートします。
*   `F2h` (PSG 1) および `F3h` (PSG 2) の両方に対して、**減衰量レジスタを最大 (Volume 15 = OFF)** に設定するデータを書き込みます。
    *   設定値: `9Fh` (Tone 0 Vol=15), `BFh` (Tone 1 Vol=15), `DFh` (Tone 2 Vol=15), `FFh` (Noise Vol=15)

## 3. サウンド制御の割り込み初期化
*   ミュージック機能などを利用する際、8253 PIT または YM2151 の割り込みを使う場合、CPU は `IM 1` モードに設定され、Z80 PIO の割り込みベクタ等が設定されます。
*   IPL 自体は、起動時およびエラー発生時に「ピー」というBEEP音（8253 PITを使用）を鳴らすルーチンを持っています。

## 4. ソフトウェアの起動シーケンス (モニタROMのロジック)
ハードウェアの初期化が完了すると、IPLは以下の流れでソフトウェア的なブート処理（メディアのチェックとOS/ソフトのロード）を行います。これはテクニカルノートの P40（IPLの構造）および P80等のソースリストから判明している仕様です。

1.  **起動メッセージの表示**:
    *   画面をクリアし、VRAMに `** MONITOR 9Z-502M **` という文字列を表示します。（※`9Z-502M` はMZ-1500のモニタROMの型番です）
2.  **メディアの自動チェックとロード**:
    *   まず、優先的にフロッピーディスク (FD) や クイックディスク (QD) の状態をチェックします。
    *   QDにメディア（BASICなど）がセットされている場合、一番先頭のファイルのインフォメーションブロックを読み込みます。
    *   ファイル名を画面に表示（例: `IPL IS LOADING`）し、続いて本体をRAM (`1200H` など) へロードします。
    *   ロード完了後、バンク切り替えによってメモリマップをオールRAMの状態にし、ロードしたプログラムの実行開始アドレスへジャンプ（起動）します。
3.  **メディア選択画面 (メニュー) の表示**:
    *   もしFDやQDがセットされていない、あるいはエラーが発生して自動起動できなかった場合は、ユーザーに入力を促す以下の**メディア選択メッセージ（メニュー）**が画面に表示されます。
        *   `F: Floppy disk`
        *   `Q: Quick disk`
        *   `C: Cassette tape`
        *   `M: Monitor`
    *   ここでユーザーがキーボードから `Q`, `C`, `F` などを押すことで、対象のデバイスから手動でロード処理（READ INFORMATION BLOCK等）が再試行されます。`M` を押すとROMモニタのコマンド入力待ち状態になります。
