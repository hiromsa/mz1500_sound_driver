# MZ-1500 FDD インターフェース (MB8876) 仕様
キーワード: `MZ-1500`, `FDD`, `Floppy Disk`, `MB8876`, `Storage`, `Media`, `Emulator`, `仕様`
【情報源: MZ-1500_Hardware_IO_Spec】

MZ-1500 には拡張フロッピーディスクドライブ (MZ-1E05 等) を接続するためのインターフェースが存在し、内部では MB8876 または互換の FDC (Floppy Disk Controller) が使用されています。

## 1. ハードウェア I/O (MB8876)
フロッピーディスクコントローラへのアクセスは以下のポートを使用します。

*   **`D8h`**: ステータスレジスタ (Read) / コマンドレジスタ (Write)
*   **`D9h` (R/W)**: トラックレジスタ
*   **`DAh` (R/W)**: セクタレジスタ
*   **`DBh` (R/W)**: データレジスタ
*   **`DCh` (W)**: モータON・ドライブ選択レジスタ (Drive Select)
*   **`DDh` (W)**: ヘッドセレクト (Head Select / サイド切り替え)

*(※サウンドドライバ等の開発においてフロッピーディスクを直接制御することはまれですが、独自OSやローダーを作成する際にはこれらのポートを用いたMB8876のコマンドシーケンスが必要になります)*
