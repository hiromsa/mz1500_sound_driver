# MZ-1500 CPU & Architecture (Z80 / クロック / 割り込み)
キーワード: `MZ-1500`, `CPU`, `Z80A`, `Clock`, `Interrupt`, `INT`, `NMI`, `Emulator`, `仕様`
【情報源: CommonSourceProjectSrc/source/src/vm/mz700/mz700.cpp, mz700.h】

## 1. CPU 基本仕様
*   **CPU**: Z80A
*   **動作クロック**: 3,579,545 Hz (約 3.58 MHz)
*   エミュレータ上のベースクロック単位として `CPU_CLOCKS` が定義されています。

## 2. 割り込み (Interrupts) ルーティングとデイジーチェーン
MZ-1500はZ80の `INT` ピンに対する割り込みルーティングが以下のようにハードウェアで組まれています。

*   **INT の発生元 (デイジーチェーン構造)**:
    *   周辺デバイス (Z80 PIO, Z80 SIO, YM2151 など) は、Z80 CPU の割り込みピンに対して**デイジーチェーン (数珠つなぎ)** 構造で接続されています。
    *   テクニカルノート P54〜P61 の解説によれば、各デバイスには優先順位があり、上位の優先順位をもつデバイスの IEI ピン (Interrupt Enable In) は H レベルに固定され、そのデバイスの IEO ピン (Interrupt Enable Out) が下位デバイスの IEI ピンに接続されます。
    *   これにより、複数のデバイスから同時に割り込み要求 (INT) が発生した場合でも、優先順位の高いデバイスだけが処理され、下位デバイスは上位デバイスの処理 (RETI 命令による復帰) が終わるまで待たされる完全なハードウェア制御が行われます。
*   **割り込みベクタとモード**:
    *   Z80 PIO などは Mode 2 による強力なベクタ割り込み機能を持っています。デバイス自身がデータバス上に割り込みベクタ (8ビット) を送出し、CPU は I レジスタの上位8ビットと組み合わせて特定のサービスルーチンへ直接ジャンプすることができます。
    *   システムタイマー等の単純な割り込みについては、ソフトウェア側で `IM 1` (Interrupt Mode 1) を設定して `$0038` 番地へジャンプさせるのも標準的な使い方です。
