# MZ-1500 BEEP音 (8253 PIT Ch.0) 仕様
キーワード: `MZ-1500`, `BEEP`, `8253`, `PIT`, `Sound`, `Audio`, `E004h`, `Emulator`, `仕様`
【情報源: CommonSourceProjectSrc/source/src/vm/mz700/mz700.cpp】

MZ-1500 では、標準の PSG 以外に、Intel 8253 PIT (Programmable Interval Timer) を利用したビープ音出力機能を持っています。これは主にキー入力時のクリック音や単純なアラーム音に使われます。

## 1. 接続と I/O ポート
*   **`E004h` (R/W)**: 8253 PIT Ch.0 のカウンタ設定レジスタ
*   **`E007h` (W)**: 8253 コントロールレジスタ
*   **出力経路**: 8253 PIT の **Ch.0 (OUT#0)** 出力がそのままスピーカーアンプに接続されており、生成されたパルスが BEEP 音としてスピーカーから鳴ります。

## 2. マスク制御
*   **`E002h` (8255 Port C) の Write**:
    *   `Bit 0` (SOUNDMSK) を使って、この 8253 Ch.0 からの BEEP 音の出力をマスク (ミュート/有効化) することができます。

## 3. タイマー割り込みの発生源
テクニカルノート P194 の解説により、8253 カウンタ0 の出力は単に音を出すだけでなく、**システム割り込みのトリガー**としても利用されていることが判明しています。
*   8253の OUT 0 の出力は、**Z80 PIO の Port A の A4** の状態によってシステム割り込み (INT 1 / INT 2) を発生させるように結線されています。
*   サウンドドライバ等で定周期のエンベロープ処理を行う場合、このカウンタ0を利用して一定間隔 (例: 1mSや70mS) ごとにCPUへ割り込みをかけることができます。
