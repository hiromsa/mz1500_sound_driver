# MZ-1500 ジョイスティック (PWM) 仕様
キーワード: `MZ-1500`, `Joystick`, `Joypad`, `PWM`, `E008h`, `V-BLANK`, `Input`, `Emulator`, `仕様`
【情報源: CommonSourceProjectSrc/source/src/vm/mz700/joystick.cpp, memory.cpp】

標準ジョイスティック (SHARP MZ-1X03 等) の状態は、I/O ポート `E008h` から読み取ります。MZ-1500 のジョイスティック入力は、V-BLANK 信号を利用したマルチプレクサ(PWM)方式となっており、アナログ的な傾きも取得可能です。

## 1. 読み取りポートと V-BLANK 状態
ポート `E008h` (R) は、画面の走査タイミング (V-BLANK) によって読み取れるデータが変化します。

### 1-A. V-BLANK = High (描画期間中) の場合
トリガーボタン (A/Bボタン) の状態が取得できます。ボタンが押下されていると `0` になります（負論理）。
*   `Bit 5 - 4`: 1P Button B
*   `Bit 3 - 2`: 1P Button A (※エミュレータ実装依存のビット割り当て。実質 1P/2P A/B の4種)
*   *(正確な資料アサイン)*: Bit 1=1P A, Bit 2=1P B, Bit 3=2P A, Bit 4=2P B

### 1-B. V-BLANK = Low (垂直ブランキング期間中) の場合
スティックの傾きがアナログ値(PWMパルス)として取得できます。
*   V-BLANK開始から 302 CPUクロック経過後にパルス送信が開始されます。
*   各軸の傾き値 (0〜255) に対し、`(値 + 10) × 28` CPUクロックの時間だけ Low になるパルスを出力します。ソフトウェア側でこの Low 期間の長さをカウントすることで傾きを検出します。
*   *(正確な資料アサイン)*: Bit 1=1P X軸, Bit 2=1P Y軸, Bit 3=2P X軸, Bit 4=2P Y軸
